= 了解適用於資料庫的 NetApp Workload Factory
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
NetApp Workload Factory for 資料庫是一項端對端的資料庫部署與維護服務，具備內建的最佳化最佳實務、自動瞬間建立複本，以及監控與解決功能。



[[what-is-netapp-workload-factory-for-databases]]
== 什麼是適用於資料庫的 NetApp Workload Factory？

NetApp Workload Factory for Databases 可發現、評估、規劃、配置及移轉 Microsoft SQL Server、PostgreSQL 和 Oracle 資料至 Amazon FSx for NetApp ONTAP（FSx for ONTAP）部署，這些部署經過最佳化，可滿足您的效能與成本預期，同時遵循業界最佳實踐。NetApp Workload Factory for Databases 持續在 FSx for ONTAP 上最佳化並管理資料庫。

link:../setup/learn-about-workload-factory.html["深入瞭解 Workload Factory"]。



[[workload-factory-benefits-for-self-managed-databases]]
== Workload Factory 對自行管理資料庫的效益

Workload Factory 為自我管理的資料庫提供最佳實務做法和自動化功能。



[[best-practices]]
=== 最佳實務

* 整合來自 AWS 雲端、Microsoft Windows 和 SQL 伺服器以及 NetApp ONTAP 的知識，用於在 EC2 執行個體上部署 SQL 伺服器。
* 整體擁有成本最佳化的部署。
* 遵循 AWS、Microsoft 和 ONTAP 最佳實務的端對端部署自動化。
* _快速建立_ 部署模式可協助您避免手冊組態的潛力陷阱。




[[automation-with-workload-factory-codebox]]
=== 使用 Workload Factory Codebox 實現自動化

Workload Factory 引入了內建自動化功能 _Codebox_。Codebox 提供以下自動化優勢：

* *程式碼片段產生*：Workload Factory 在資源建立期間產生基礎架構即程式碼（IaC）片段，從而實現與現有協調工作流程的無縫整合。
* *基礎架構即程式碼輔助工具*：Codebox 是一個基礎架構即程式碼（IaC）輔助工具，可協助開發人員和 DevOps 產生程式碼，以執行 Workload Factory 支援的任何作業。
* *程式碼檢視器和自動化目錄*：Codebox 提供程式碼檢視器以快速分析自動化，以及自動化目錄以供未來快速重複使用。




[[workload-factory-for-databases-features]]
=== Workload Factory for Databases 功能

Workload Factory for Databases 提供以下功能：

* *成本估算*：使用節省計算器評估潛在的成本節省，該計算器估算並詳細列出現有 Microsoft SQL Server 和 Oracle 部署（使用 Elastic Block Store、FSx for Windows File Server 和內部部署）與 FSx for ONTAP 相比的儲存、運算、SQL 授權、快照和複製的逐項成本。
* *簡單、快速的部署*：透過內建的 NetApp、Microsoft 和 Amazon 最佳實踐，簡化和最佳化主機、資料庫和沙箱的配置，消除在 AWS 上對 Microsoft SQL Server 和 PostgreSQL 執行個體進行手動配置的複雜性。
+
** 使用 Workload Factory 控制台的 _Quick_ 或 _Advanced_ 建立模式進行部署，或透過 Codebox 建立、重複使用和自訂 AWS CloudFormation 範本，以便在多個環境中進行未來的部署。
** 按需建立隔離資料庫，提供儲存配置和沙箱複本，可用於測試、整合、診斷和培訓，而不會影響正式作業資料。


* *Well-architected 評估功能*：持續掃描您的 Microsoft SQL Server 和 Oracle 環境，產生包含洞察、機會和建議的綜合報告，協助您根據 AWS 最佳實務做法實現卓越營運、安全性、可靠性、效能效率和成本最佳化。
* *錯誤分析*：使用 AI 分析器分析和疑難排解記錄錯誤，以取得詳細的錯誤訊息、疑難排解步驟和解決問題的建議。
* *集中管理*：在一個位置即可管理 FSx for ONTAP 上的 Microsoft SQL Server、Oracle 和 PostgreSQL 資源。在 Workload Factory 中，您可以查看已連線的基礎架構、AWS 帳戶、憑證、已連線的 FSx for ONTAP 檔案系統、儲存使用情況（包括 NFS 磁碟區和 iSCSI LUN）、保護狀態、效能、架構良好狀態和錯誤分析。




[[benefits-of-amazon-fsx-for-ontap-for-self-managed-databases]]
== Amazon FSx for ONTAP 對自我管理資料庫的優勢

* *持久性、可用度和可靠性*：FSx for ONTAP 提供多種功能，增強託管在 FSx for ONTAP 上的自我管理資料庫的持久性和可用度，例如支援單一和多個可用區域部署的高可用度、應用程式整合的 Snapshot 快照技術、使用複寫改進的災難恢復，以及高效的備份。
* *效能與擴充性*：FSx for ONTAP 提供效能最佳化，具有高處理量、低延遲、高速網路連線和擴充性，可透過多個檔案系統來擴充工作負載所需的彙總效能。
* *資料管理員與效率*：FSx for ONTAP 提供多種增強資料管理員和效率的功能，例如節省空間的精簡 Clone、資源隨需配置、壓縮和重複資料刪除，以及將不常用的資料分層至容量資源池。


link:../fsx-storage/learn-fsx-ontap.html["了解適用於 Workload Factory 的 FSx for ONTAP"^]。



[[tools-to-use-netapp-workload-factory]]
== 使用 NetApp Workload Factory 的工具

您可以將 NetApp Workload Factory 與下列工具搭配使用：

* *Workload Factory 控制台*：Workload Factory 控制台提供應用程式和專案的視覺化、整體檢視。
* *NetApp Console*：NetApp Console 提供混合介面體驗，讓您可以將 Workload Factory 與其他 NetApp 資料服務搭配使用。
* *Ask me*：使用 Ask me AI 助理來提問，無需離開 Workload Factory 主控台即可了解更多關於 Workload Factory 的資訊。您可以從 Workload Factory 說明選單存取 Ask me。
* *CloudShell CLI*：Workload Factory 包含一個 CloudShell CLI，可透過單一、以瀏覽器為基礎的 CLI，跨帳戶管理及操作 AWS 與 NetApp 環境。從 Workload Factory 主控台的頂部列存取 CloudShell。
* *REST API*：使用 Workload Factory REST API 部署和管理您的 FSx for ONTAP 檔案系統和其他 AWS 資源。
* *CloudFormation*：使用 AWS CloudFormation 程式碼執行您在 Workload Factory 主控台中定義的行動，以從您 AWS 帳戶中的 CloudFormation 堆疊，建模、資源配置及管理 AWS 與第三方資源。
* *NetApp Terraform 供應商*：使用 Terraform 建置和管理在 Workload Factory 主控台中產生的基礎架構工作流程。
