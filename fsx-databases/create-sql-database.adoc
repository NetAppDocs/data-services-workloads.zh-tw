= 在 NetApp Workload Factory for Databases 中建立 Microsoft SQL 資料庫
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
建立新的 Microsoft SQL 資料庫後，您就可以在 NetApp Workload Factory for Databases 中管理該資源。

.關於此任務
建立資料庫時，FSx for ONTAP 檔案系統中會建立兩個新 Volume，其中包含獨立的 LUN，用於存放資料庫的資料和日誌檔。新資料庫中的資料庫檔案採用精簡配置，僅使用分配給新資料庫的總大小中的幾 MB。

如果要隔離資料庫的儲存設備，可以使用 _虛擬安裝點_。虛擬安裝點可以將資料庫整合在主機的幾個公用磁碟機上。

在 workload factory 中建立資料庫需要 _檢視、規劃和分析_ 權限。或者，您可以複本或下載部分完成的程式碼範本，在 workload factory 之外完成此操作。link:../fsx-storage/permissions-reference-fsx.html["了解 Workload Factory 權限"^] 決定您要使用哪種模式。


NOTE: 使用 SMB 協定的 Microsoft SQL Server 不支援建立資料庫。

.開始之前
在建立新資料庫之前，請完成以下先決條件。

* *憑證和權限*：您必須具備 link:../fsx-storage/add-credentials.html["AWS 帳戶憑證和 _operations and remediation_ 權限"^] 才能在 Workload Factory 中建立新資料庫。
+
或者，您可以使用 Codebox 建立範本的複本，以便使用 REST API 在 workload factory 外部署資料庫link:../admin/codebox-automation.html["了解更多關於 Codebox 自動化"^]。

* *Windows 主機*：如果您使用 _快速建立_ 模式，則必須在 Microsoft SQL Server 上有足夠的可用磁碟機代號，以便為新資料庫建立新磁碟機。
* *Microsoft SQL Server*：您必須在資料庫的工作負載工廠中擁有代管的 Microsoft SQL Server，以作為新資料庫的主機。
* *AWS Systems Manager*：確保透過 AWS Systems Manager 在 Microsoft SQL 主機上啟用 `NT Authority\SYSTEM`使用者權限。

== 建立資料庫

在 Workload Factory 中，您可以使用「快速建立」或「進階建立」部署模式來完成此工作。

[role="tabbed-block"]
====
.快速建立
--
.步驟
. 登入 link:https://console.netapp.com["NetApp Console"^]。
. 選擇選單 image:workloads-menu-icon.png["漢堡選單圖示用於導覽至 Workloads ，這是 Workload Factory 的選單項目"]，*工作負載* > *資料庫*。
. 從資料庫選單中，選擇 *庫存*。
. 在清單中，選擇 *Microsoft SQL Server* 作為資料庫引擎類型。
. 選擇具有代管 SQL Server 執行個體的資料庫伺服器來建立資料庫。
. 按一下代管執行個體的行動選單，然後選擇 *建立使用者資料庫*。
. 在「建立使用者資料庫」頁面的「資料庫資訊」下，提供以下資訊：
+
.. *資料庫名稱*：輸入資料庫名稱。
.. *排序規則*：選擇資料庫的排序規則。已選取 Microsoft SQL Server 上的預設排序規則 SQL_Latin1_General_CP1_CI_AS"。


. 在「檔案設定」中，提供以下資訊：
+
.. *檔案設定模式*：選擇*快速建立*。
.. *檔案名稱和路徑*：
+
*** *資料檔案名稱*：輸入資料檔案名稱。
*** *日誌檔名稱*：請輸入日誌檔名稱。


.. *檔案大小*：輸入資料庫的資料大小和日誌大小。


. 按一下 *Create* 。
+
或者，如果您現在想要變更任何這些預設設定，請將 *檔案設定模式* 變更為 *進階建立*。



--
.進階建立
--
.步驟
. 登入 link:https://console.netapp.com["NetApp Console"^]。
. 選擇選單 image:workloads-menu-icon.png["漢堡選單圖示用於導覽至 Workloads ，這是 Workload Factory 的選單項目"]，*工作負載* > *資料庫*。
. 從資料庫選單中，選擇 *庫存*。
. 在清單中，選擇 *Microsoft SQL Server* 作為資料庫引擎類型。
. 選擇具有代管 SQL Server 執行個體的資料庫伺服器來建立資料庫。
. 按一下代管執行個體的行動選單，然後選擇 *建立使用者資料庫*。
. 選擇 *建立使用者資料庫*。
. 在「建立使用者資料庫」頁面的「資料庫資訊」下，提供以下資訊：
+
.. *資料庫名稱*：輸入資料庫名稱。
.. *排序規則*：選擇資料庫的排序規則。已選取 Microsoft SQL Server 上的預設排序規則 SQL_Latin1_General_CP1_CI_AS"。


. 在「檔案設定」中，提供以下資訊：
+
.. *檔案設定模式*：選擇*進階建立*。
.. *檔案名稱和路徑*：
+
... *資料檔案*：選擇磁碟機代號並輸入資料檔案名稱。
+
（選用）勾選 *虛擬安裝點* 的方塊。

... *日誌檔*：選取磁碟機代號並輸入日誌檔名稱。
+
（選用）勾選 *虛擬安裝點* 的方塊。



.. *檔案大小*：輸入資料庫的資料大小和日誌大小。


. 按一下 *Create* 。


--
====
如果您建立了資料庫主機，則可以在「作業監控」標籤中查看作業進度。
