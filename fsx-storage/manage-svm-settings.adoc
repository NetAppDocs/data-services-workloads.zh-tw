= 在 NetApp Workload Factory 中管理儲存設備 VM 設定
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
在 NetApp Workload Factory 中管理儲存設備 VM 的設定。您可以為儲存設備 VM 設定及更新 Active Directory、更新儲存設備 VM 密碼，以及管理儲存設備 VM 的標籤。



[[configure-and-update-ad-for-a-storage-vm-in-netapp-workload-factory]]
== 在 NetApp Workload Factory 中為儲存設備 VM 設定及更新 AD

在 NetApp Workload Factory 的 FSx for ONTAP 檔案系統中，為儲存設備 VM 設定與更新 Active Directory。

設定和更新儲存設備虛擬機器的 Active Directory 也適用相同的步驟。

.步驟
. 登入 link:https://console.netapp.com["NetApp Console"^]。
. 選擇選單 image:workloads-menu-icon.png["漢堡選單圖示用於導覽至 Workloads ，這是 Workload Factory 的選單項目"]，*工作負載* > *儲存設備* > *FSx for ONTAP*。
. 從 *FSx for ONTAP* 中，選擇包含要更新之儲存設備 VM 的檔案系統動作選單，然後選擇 *管理*。
. 在 Storage VMs 下的檔案系統總覽中，選擇 *管理*。
. 在「管理儲存設備虛擬機器」畫面上，選擇要為其設定 Active Directory 的儲存設備虛擬機器的操作選單，然後選擇 *基本操作* > *管理 AD 組態*。
. 在「管理 AD 組態」頁面上，提供以下資訊：
+
.. *要參加的 Active Directory 網域*：輸入您的 Active Directory 的完整網域名稱（FQDN）。
.. *DNS IP 位址*：輸入最多三個 IP 位址，以逗號分隔。
.. *SMB 伺服器 NetBIOS 名稱*：輸入要為儲存設備虛擬機器建立的 Active Directory 電腦物件的 SMB 伺服器 NetBIOS 名稱。這是此 SVM 在 Active Directory 中的名稱。
.. *使用者名稱*：輸入您現有 Active Directory 中服務帳戶的使用者名稱。
+
請勿包含網域前綴或後綴。針對 `EXAMPLE\ADMIN`，請使用 `ADMIN`。

.. *密碼*：請輸入服務帳戶的密碼。
.. *組織單元（OU）*：輸入組織單元。
+
OU 是您要將檔案系統參加的組織單元的辨識路徑名稱。

.. *委派管理員群組*：選擇性輸入委派的檔案系統管理員群組。
+
委派管理員群組是 Active Directory 中可以管理檔案系統的群組的名稱。

+
如果您使用的是 AWS Managed Microsoft AD，則必須指定一個群組，例如 AWS Delegated FSx Administrators、AWS Delegated Administrators，或是對 OU 具有委派權限的自訂群組。

+
如果您要連線到自行管理的 AD，請使用 AD 中的群組名稱。預設群組是 `Domain Admins`。



. 選擇 *Apply*。




[[manage-storage-vm-tags]]
== 管理儲存設備 VM 標籤

標籤可以幫助您對資源進行分類。您可以在 NetApp Workload Factory 中隨時為儲存設備 VM 新增、編輯和移除標籤。

.步驟
. 登入 link:https://console.netapp.com["NetApp Console"^]。
. 選擇選單 image:workloads-menu-icon.png["漢堡選單圖示用於導覽至 Workloads ，這是 Workload Factory 的選單項目"]，*工作負載* > *儲存設備* > *FSx for ONTAP*。
. 從 *FSx for ONTAP* 中，選擇包含要更新之儲存設備 VM 的檔案系統動作選單，然後選擇 *管理*。
. 在 Storage VMs 下的檔案系統總覽中，選擇 *管理*。
. 在「管理儲存設備 VM」畫面上，選擇要編輯標籤的儲存設備 VM 的操作選單，然後選擇 *基本操作* > *編輯儲存設備 VM 標籤*。
. 在「編輯儲存設備 VM 標籤」頁面上，新增、編輯或移除標籤。
+
儲存設備虛擬機器最多可以套用 50 個標籤。

. 選擇 *Apply*。




[[reset-the-storage-vm-password-in-netapp-workload-factory]]
== 在 NetApp Workload Factory 中重設儲存設備 VM 密碼

必要時，在 NetApp Workload Factory 中重設儲存設備 VM 的密碼。

.步驟
. 登入 link:https://console.netapp.com["NetApp Console"^]。
. 選擇選單 image:workloads-menu-icon.png["漢堡選單圖示用於導覽至 Workloads ，這是 Workload Factory 的選單項目"]，*工作負載* > *儲存設備* > *FSx for ONTAP*。
. 從 *FSx for ONTAP* 中，選擇要重設儲存設備 VM 密碼的檔案系統的操作選單，然後選擇 *管理*。
. 在 Storage VMs 下的檔案系統總覽中，選擇 *管理*。
. 在「管理儲存設備虛擬機器」畫面上，選擇要重設密碼的儲存設備虛擬機器的操作選單，然後選擇 *基本操作* > *重設密碼*。
. 在「重設密碼」對話方塊中，提供以下資訊：
+
.. *新密碼*：請輸入儲存設備虛擬機器的新密碼。
.. *確認密碼*：請再次輸入新密碼確認。
