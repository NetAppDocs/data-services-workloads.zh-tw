= 在 NetApp Workload Factory 中檢視 Google Cloud NetApp Volumes 儲存資源池
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
檢視您的 Google Cloud NetApp Volumes 儲存資源池及其在 NetApp Workload Factory 中的詳細資訊。

.步驟
. 登入 link:https://console.netapp.com["NetApp Console"^]。
. 選擇選單 image:workloads-menu-icon.png["漢堡選單圖示用於導覽至 Workloads ，這是 Workload Factory 的選單項目"]，*儲存設備* > *Google Cloud NetApp Volumes*。
. 使用 *專案*、*憑證* 和 *區域* 篩選器來限定顯示的儲存資源池範圍。
. 審查儲存資源池表格，其中顯示名稱、狀態、服務層級和容量等詳細資訊。
+
儲存資源池的服務層級為標準、進階、極致、Flex 檔案或 Flex 統一。對於 Flex 統一儲存資源池，模式會顯示為預設或 ONTAP，對於所有其他服務層級，則顯示為預設。

. 選擇儲存資源池的名稱以開啟其詳細資料，包括處理量和執行摘要。
