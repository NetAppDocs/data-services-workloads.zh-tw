= NetApp Workload Factory 快速入門
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
使用者可從 NetApp Console 以雲端資料服務的形式存取 NetApp Workload Factory。若要開始使用 Workload Factory，請在 NetApp Console 中註冊並建立帳戶，並新增雲端供應商認證資料，以便 Workload Factory 可以直接管理您的資源並最佳化您的工作負載。

在開始之前，您應該要了解link:learn-about-workload-factory.html["Workload Factory"]。
