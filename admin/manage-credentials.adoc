= 從 NetApp Workload Factory 移除憑證
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
如果您不再需要某組憑證，可以從 Workload Factory 中刪除它們。您只能刪除未與 FSx for ONTAP 檔案系統關聯的憑證。

.步驟
. 登入 link:https://console.netapp.com["NetApp Console"^]。
. 從 NetApp Console 選單中，選取 *工作負載* > *管理* > *憑證*。
. 在 *憑證* 頁面上，執行以下操作：
+
** 在 Workload Factory 控制台中，選擇一組憑證的行動選單，然後選擇 *移除*。選擇 *移除* 以進行確認。
** 在 NetApp Console 中，選擇一組憑證的行動選單，然後選擇 *刪除*。選擇 *刪除* 以確認。
