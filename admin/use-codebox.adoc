= 在 NetApp Workload Factory 中使用 Codebox 進行自動化
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以使用 Codebox 產生執行 NetApp Workload Factory 支援的任何操作所需的程式碼。您可以產生可使用 Workload Factory REST API、AWS CLI 和 AWS CloudFormation 來使用和執行的程式碼。

Codebox 遵守 Workload Factory 權限原則，會根據 Workload Factory 帳戶中為每個使用者提供的 AWS 權限，在程式碼中填入適當的資料。此程式碼可作為範本使用，您可以在執行程式碼之前填寫缺少的資訊（例如憑證）或自訂某些資料。



[[how-to-use-codebox]]
== 如何使用 Codebox

當您在 NetApp Console 的使用者介面精靈中輸入值時，您可以在完成每個欄位時看到 Codebox 中的資料更新。當您完成精靈，但在選擇頁面底部的 *建立* 按鈕之前，請選擇 image:button-copy-codebox.png["複本按鈕"] 以在 Codebox 中製作複本，來擷取建置組態所需的程式碼。例如，這個建立新 Microsoft SQL Server 的快照顯示了 VPC 和可用度區域的精靈項目，以及 Codebox 中 REST API 實作的等效項目。

image:screenshot-codebox-example1.png["快照顯示如何在 UI 中建立 Microsoft SQL Server，以及 Codebox 中 VPC 和可用度區域的對應項目。"]

某些程式碼格式還允許您選擇下載按鈕，將程式碼儲存到檔案中，以便匯入到其他系統。如有需要，您可以在下載後編輯程式碼，使其適用於其他 AWS 帳戶。



[[use-cloudformation-code-from-codebox]]
== 使用來自 Codebox 的 CloudFormation 程式碼

您可以複本從 Codebox 產生的 CloudFormation 程式碼，然後在您的 AWS 帳戶中產品發表 Amazon Web Services CloudFormation 堆疊。CloudFormation 將執行您在 Workload Factory UI 中定義的動作。

根據您是部署 FSx for ONTAP 檔案系統、建立帳戶憑證，還是執行其他 Workload Factory 操作，使用 CloudFormation 程式碼的步驟可能會有所不同。

請注意，出於安全性原因，CloudFormation 產生的 YAML 檔案中的程式碼會在 7 天後過期。

.開始之前
* 您需要擁有登入 AWS 帳戶的憑證。
* 您需要擁有以下使用者權限才能使用 CloudFormation 堆疊：
+
[%collapsible]
====
[source, json]
----
{
    "Version": "2012-10-17",
    "Statement": [
        {
            "Effect": "Allow",
            "Action": [
                "cloudformation:CreateStack",
                "cloudformation:UpdateStack",
                "cloudformation:DeleteStack",
                "cloudformation:DescribeStacks",
                "cloudformation:DescribeStackEvents",
                "cloudformation:DescribeChangeSet",
                "cloudformation:ExecuteChangeSet",
                "cloudformation:ListStacks",
                "cloudformation:ListStackResources",
                "cloudformation:GetTemplate",
                "cloudformation:ValidateTemplate",
                "lambda:InvokeFunction",
                "iam:PassRole",
                "iam:CreateRole",
                "iam:UpdateAssumeRolePolicy",
                "iam:AttachRolePolicy",
                "iam:CreateServiceLinkedRole"
            ],
            "Resource": "*"
        }
    ]
}
----
====


.步驟
. 使用 NetApp Console 定義您要執行的作業後，請複製 Codebox 中的程式碼。
. 選取 *重新導向至 CloudFormation*，隨即顯示「重新導向至 CloudFormation」頁面。
. 開啟另一個瀏覽器視窗，登入 AWS Management Console。
. 從「重新導向至 CloudFormation」頁面中選取 *繼續*。
. 登入要執行程式碼的 AWS 帳戶。
. 在「快速建立堆疊」頁面上的「功能」下，選擇 *我確認 AWS CloudFormation 可能會……*。
. 選擇 *建立堆疊*。
. 從 AWS 或 Workload Factory 監控進度。




[[use-rest-api-code-from-codebox]]
== 使用來自 Codebox 的 REST API 程式碼

您可以使用從 Codebox 產生的 Workload Factory REST API 來部署和管理您的 FSx for ONTAP 檔案系統和其他 AWS 資源。

您可以從任何支援 curl 且具有網路連線的主機執行 API。

請注意，驗證權杖在 Codebox 中是隱藏的，但當您複本並貼上 API 呼叫時，它們會自動填入。

.步驟
. 使用 NetApp Console 定義要執行的操作後，複製 Codebox 中的 API 程式碼。
. 貼上程式碼並在主機系統上執行。




[[use-aws-cli-code-from-codebox]]
== 使用 Codebox 中的 AWS CLI 程式碼

您可以使用從 Codebox 產生的 Amazon Web Services CLI 來部署和管理您的 FSx for ONTAP 檔案系統和其他 AWS 資源。

.步驟
. 使用 NetApp Console 定義您要執行的操作後，請複製 Codebox 中的 AWS CLI。
. 開啟另一個瀏覽器視窗，登入 AWS Management Console。
. 貼上程式碼並執行。




[[use-terraform-from-codebox]]
== 使用 Codebox 中的 Terraform

您可以使用 Terraform 來部署和管理您的 FSx for ONTAP 檔案系統和其他 AWS 資源。

.開始之前
* 您需要一台安裝了 Terraform 的系統（Windows/Mac/Linux）。
* 您需要擁有登入 AWS 帳戶的憑證。


.步驟
. 使用 NetApp Console 定義您要執行的作業後，請從 Codebox 下載 Terraform 程式碼。
. 將下載的指令碼歸檔複製到安裝了 Terraform 的系統中。
. 解壓縮 zip 檔案，然後按照 README.md 檔案中的步驟操作。
